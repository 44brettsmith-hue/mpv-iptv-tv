# MPV IPTV for TV

Install file for the MPV IPTV player on Google TV, Android TV and Fire TV. This repository only
holds the APK; it contains no channels, no playlists and no
login details. You sign in on each TV with your own provider.

## Quick reference

| | |
|---|---|
| **Downloader code** | **3294452** |
| Short link | https://aftv.news/3294452 |
| Points to | `https://github.com/44brettsmith-hue/mpv-iptv-tv/raw/main/mpv-iptv-tv.apk` |
| Updates | In the app: Settings → App → Check for updates |

The code always points at the newest APK in this repository, so it never needs changing.
Keep the APK's file name and location the same when publishing new builds.

## Install with Downloader

1. Install **Downloader** by AFTVnews from the Play Store (Amazon Appstore on Fire TV).
2. Allow it to install apps:
   - Google TV: Settings → System → About → select **Android TV OS build** 7 times, then
     Settings → Apps → Security & restrictions → Unknown sources → turn on **Downloader**.
   - Fire TV: Settings → My Fire TV → Developer options → Install unknown apps → **Downloader**.
3. Open Downloader and enter the code **3294452** (or this link), then choose Install:

   `https://github.com/44brettsmith-hue/mpv-iptv-tv/raw/main/mpv-iptv-tv.apk`

4. Open **MPV IPTV**. Scan the QR code with your phone to type your login there, or use the remote.

The same link always gives the newest version; installing it again updates the app and keeps
your login and favourites.

From version 0.1.11 the app can update itself: Settings → App → Check for updates. The first
time, Android asks you to allow MPV IPTV to install apps.
